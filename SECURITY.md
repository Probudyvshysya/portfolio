# Безопасность

## Что в этом репозитории есть и чего нет

- **Нет** секретов, ключей, токенов, адресов серверов, данных клиентов и личных данных. Описания проектов обезличены,
  скриншоты сняты с демо-версии на отдельной базе с выдуманными клиентами.
- **Нет** кода закрытых систем (Reels Studio, радар закупок, боты) — только описание и модель безопасности.
- **Есть** открытый код агентов проверки документов (`agents/doc-verification`): работает локально, без сети
  и внешних сервисов, ничего не хранит.

## Агенты проверки документов: модель угроз

Документы приходят от третьих лиц, поэтому разбор исходит из того, что файл может быть враждебным.

| Угроза | Защита |
|---|---|
| XXE и «billion laughs» в `.docx` | XML разбирается через `defusedxml` с запретом DTD, сущностей и внешних ссылок — на уровне парсера, поэтому кодировка UTF-16 его не обходит; в настоящем Word DTD не бывает |
| Zip-бомба в `.docx` | считаются реально распакованные байты, а не размер из заголовка архива: предел на часть (50 МБ) и на все части вместе (100 МБ) |
| Перегрузка разбора | пределы: файл до 200 МБ, до 5 000 частей в архиве, до 2 000 страниц и 20 млн знаков текста PDF; превышение — честный статус «не прочитан» или «прочитано частично» с причиной |
| Повреждённый или поддельный файл | ошибка чтения — статус «не прочитан» с причиной; проверка остального комплекта продолжается |
| Незаметно непрочитанный документ | светофор считает непрочитанное и краснеет; неподдерживаемый формат не пропускается молча |
| Утечка данных | нет сетевых запросов, внешних сервисов и секретов |

Каждое изменение проходит тесты в GitHub Actions; зависимости обновляет Dependabot.
