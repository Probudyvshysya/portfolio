# Спецификация № 1 к договору поставки № 14/26-Ж

Документ выдуман для демонстрации. Организации, номера и цифры не относятся к реальным сделкам.

## 1. Товар, количество, цена

Товар: жмых соевый, насыпью.
Количество: 1 000 тонн (±5 % в опционе Поставщика по п. 3 договора).
Цена: 38 500 рублей за одну тонну без НДС.
Стоимость партии по Спецификации: 38 500 000 рублей без НДС.

## 2. Срок и условия отгрузки

Срок отгрузки: с 1 по 10 октября 2026 года включительно.
Базис поставки: FCA станция отправления Поставщика, вагоны-хопперы.
Станция назначения и реквизиты грузополучателя сообщаются Покупателем до 28 сентября 2026 года.

## 3. Базисные показатели качества

| Показатель | Норма |
|---|---|
| Сырой протеин, в пересчёте на абсолютно сухое вещество | не менее 42,0 % (базис) |
| Влажность | не более 10,0 % (базис) |
| Сырой жир | не более 9,0 % |
| Сырая клетчатка | не более 7,0 % |
| Активность уреазы (изменение pH) | 0,1–0,3 |
| Посторонние примеси, зараженность вредителями | не допускаются |

Скидки за отклонение от базиса и право отказа от партии — по п. 5 договора.

## 4. Документы на партию

С каждой партией Поставщик передаёт: удостоверение качества, железнодорожные накладные,
ветеринарный сопроводительный документ, счёт.
