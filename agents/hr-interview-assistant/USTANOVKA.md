# HR-помощник: установка и обслуживание

Инструкция для системного администратора. Помощник ставится на компьютер HR и работает там же: облачных сервисов нет,
страница открывается только на этом компьютере.

## Что понадобится

- Windows 10 или 11, 16 ГБ оперативной памяти, 15 ГБ свободного места. Видеокарта не обязательна, с ней разбор быстрее.
- Python 3.12, ffmpeg, Ollama (бесплатные, ставятся с официальных сайтов или из комплекта).
- Микрофон у HR. Для записи созвона лучше наушники: так голос собеседника не попадает в микрофон.

## Установка

1. Скопировать папку `hr-interview-assistant` на компьютер HR, например в `C:\HR-pomoshchnik`.
2. Поставить Python 3.12, ffmpeg (добавить в PATH) и Ollama.
3. В папке комплекта создать окружение и поставить библиотеки с зафиксированными версиями:
   ```
   python -m venv .venv
   .venv\Scripts\pip install -r requirements-lock.txt
   ```
4. Загрузить модели:
   ```
   ollama pull qwen3:4b-instruct-2507-q4_K_M
   ollama pull bge-m3
   ```
   Модель распознавания речи GigaAM (430 МБ) скачивается сама при первом разборе в `%USERPROFILE%\.cache\gigaam`.
   Модели деления по голосам (нужны только для записи в одну дорожку) скачиваются отдельно с релизов sherpa-onnx
   в папку `modeli`: `sherpa-onnx-pyannote-segmentation-3-0/model.onnx` и `wespeaker_en_voxceleb_resnet34_LM.onnx`.
5. Проверить установку:
   ```
   .venv\Scripts\python PROVERKA.py
   ```
   Скрипт проходит по пунктам (библиотеки, модели, микрофон, память, порт) и по каждому пишет ✅ или ❌ с подсказкой.
6. Сделать HR ярлык на `ZAPUSK.cmd`. Он запускает модель с нужными настройками и открывает страницу
   `http://127.0.0.1:8790`.

## Настройки

Задаются переменными среды (например, в `ZAPUSK.cmd`):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `HR_INTERNET` | `1` | `0` отключает проверку фактов в интернете, остаётся только база знаний |
| `HR_POTOKI` | `4` | сколько потоков процессора отдавать разбору; остальное остаётся HR для работы |
| `HR_DANNYE` | папка `dannye` комплекта | где хранить записи и заключения |
| `HR_SROK_DNEY` | `30` | через сколько дней после отказа удалять данные кандидата; срок выбирает юрист компании |
| `HR_MODEL` | `qwen3:4b-instruct-2507-q4_K_M` | модель для заключений; на сервере с видеокартой можно взять крупнее (сначала `ollama pull`) |
| `OLLAMA_FLASH_ATTENTION`, `OLLAMA_KV_CACHE_TYPE` | `1`, `q8_0` | экономный режим памяти модели; без него на 16 ГБ модель может не загрузиться |

Порт страницы `8790` меняется в `hr/server.py` и `ZAPUSK.cmd`.

## Где что лежит

| Что | Где |
|---|---|
| Записи, расшифровки, заключения | `dannye/kandidaty/<номер>/` |
| Вакансии и профили должностей | `dannye/vakansii/` |
| Поправки HR (правила помощника) | `dannye/pravila.json` |
| Журнал действий | `dannye/zhurnal.log` (без ФИО) |
| Журнал выхода в интернет | `dannye/vyhod.log` |
| База знаний (ГОСТы, регламенты) | `znaniya/*.md`, `znaniya/*.txt` |
| Словарь терминов для распознавания | `znaniya/slovar-zamen.txt` |

Резервная копия: скопировать папку `dannye` на зашифрованный носитель или в защищённую сетевую папку.
Восстановление: положить её обратно. Копию делайте хотя бы раз в неделю: при поломке компьютера без неё
пропадут записи и история решений по кандидатам.

## Безопасность

- Сервер слушает только `127.0.0.1`: с других компьютеров страница не открывается. Запросы с чужих сайтов
  (проверка заголовков Host и Origin) отклоняются.
- Распознавание речи и модель работают на этом компьютере. В интернет уходят только общие поисковые вопросы
  для проверки фактов, без имени, цифр-идентификаторов и цитат кандидата. Каждый запрос пишется в `vyhod.log`,
  его же HR видит на вкладке «Безопасность». Выход в интернет отключается переменной `HR_INTERNET=0`.
- Без отметки о согласии кандидата запись и загрузка не запускаются.
- При решении «Отказ» данные кандидата удаляются автоматически через 30 дней (меняется в `HR_SROK_DNEY`).
  В журнале остаются номер и даты, без ФИО. Резюме откликов удаляются так же, после отправленного отказа.
- Решение по кандидату принимает HR, помощник готовит материал. Отказ кандидату помощник сам не отправляет никогда.
- **Шифрование диска обязательно.** Включите BitLocker на диске, где лежит папка `dannye`
  (Панель управления → Шифрование диска BitLocker), ключ восстановления сохраните у ИБ.
  Без шифрования при краже компьютера или вирусе-вымогателе записи голосов кандидатов окажутся у посторонних.
- Под HR заведите отдельную учётную запись Windows без прав администратора. Папку `dannye` откройте только ей.

## База знаний и словарь

Документы компании (регламенты, ГОСТы, должностные инструкции) кладутся в папку `znaniya` в формате `.md` или `.txt`
либо загружаются на вкладке «База знаний». В `.md` каждый раздел `## …` становится отдельным пунктом, на который
помощник ссылается. Индекс пересобирается сам при изменении документов.

Если распознавание систематически искажает термин, добавьте строку в `znaniya/slovar-zamen.txt`:
`как слышится => как правильно` (регулярное выражение, регистр не важен).

## Если что-то не работает

| Признак | Что сделать |
|---|---|
| На странице «модель не запущена» | запустить `ZAPUSK.cmd`; проверить, что Ollama установлен |
| Разбор в статусе «ошибка» | текст ошибки виден в карточке кандидата; кнопка «Повторить разбор» |
| Не пишется звук собеседника | в Windows проверить устройство вывода по умолчанию: запись идёт с него |
| Компьютер тормозит во время разбора | уменьшить `HR_POTOKI` до 2 |
| Порт 8790 занят | поменять порт в `hr/server.py` и `ZAPUSK.cmd` |
