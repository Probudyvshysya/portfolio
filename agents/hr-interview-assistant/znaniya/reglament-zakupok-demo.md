# Регламент отдела закупок ООО «Сибирский зерновой двор» (ДЕМО — компания и регламент выдуманы)

## Работа во ФГИС «Зерно»
Менеджер по закупкам сам оформляет партии и сопроводительные документы (СДИЗ) во ФГИС «Зерно» по своим сделкам.
Без оформленного СДИЗ партию на элеватор не принимаем. Менеджер должен уметь сам проверить СДИЗ поставщика.

## Приёмка по качеству
Каждую партию проверяет лаборатория элеватора. Класс пшеницы определяем по ГОСТ 9353-2016 по худшему показателю.
Если показатели ниже заявленного класса — пересчёт цены по фактическому классу, решение согласует начальник отдела.

## Поставщики без НДС
Цены поставщиков на УСН и с НДС сравниваем, приведя к одной базе. Предложение без НДС принимаем, только если цена ниже
на величину невозмещаемого НДС.

## Отчётность
Реестр сделок — в 1С, раз в неделю отчёт начальнику отдела: объём, средняя цена, отклонения по качеству.
