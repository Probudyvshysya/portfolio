# ГОСТ 9353-2016 «Пшеница. Технические условия»

Источник: межгосударственный стандарт, введён в РФ с 01.07.2018 взамен ГОСТ 9353-90. Полный текст — `isxodniki/gost-9353-2016.pdf`.
Ниже — выжимка ключевых норм, сверенная с разделом 5 и таблицей 2 стандарта.

## Классы мягкой пшеницы (п. 5.1, таблица 2)
Мягкую пшеницу в зависимости от качества зерна подразделяют на 5 классов (п. 5.1; для твёрдой пшеницы — таблица 3).

## Количество клейковины по классам мягкой пшеницы (таблица 2)
Количество (массовая доля сырой) клейковины, %, не менее:
- 1 класс — не менее 32,0 %
- 2 класс — не менее 28,0 %
- 3 класс — не менее 23,0 %
- 4 класс — не менее 18,0 %
- 5 класс — не ограничивается
Пример: клейковина 21 % — это ниже нормы 3 класса (23 %), но выше нормы 4 класса (18 %), то есть 4 класс.

## Массовая доля белка по классам мягкой пшеницы (таблица 2)
Массовая доля белка в пересчёте на сухое вещество, %, не менее: 1 класс — 14,5; 2 класс — 13,5; 3 класс — 12,0;
4 класс — 10,0; 5 класс — не ограничивается.

## Натура мягкой пшеницы (таблица 2)
Натура, г/л, не менее: 1 и 2 класс — 750; 3 класс — 730; 4 класс — 710; 5 класс — не ограничивается.

## Влажность (окончание таблицы 2)
Влажность, %, не более — 14,0 для всех классов мягкой пшеницы.

## Сорная и зерновая примесь (окончание таблицы 2)
Сорная примесь, %, не более: 1–4 класс — 2,0; 5 класс — 5,0. В том числе минеральная примесь: 1–4 класс — 0,3; 5 класс — 1,0.
Зерновая примесь, %, не более: 1–4 класс — 5,0; 5 класс — 15,0.

## Методы контроля (раздел 8)
Количество и качество клейковины определяют по ГОСТ 13586.1 (п. 8.10).
